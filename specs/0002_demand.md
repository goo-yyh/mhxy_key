# 无敌小铃铛需求文档

- 文档编号：0002
- 日期：2026-06-27
- 应用名称：无敌小铃铛
- Bundle Identifier：`com.yuyuehui.mhxykey`
- 图标资产：`assets/app-icon.png`
- 目标平台：macOS、Windows
- 技术栈：Tauri + React + Ant Design

## 1. 背景与目标

开发一个轻量级桌面程序，用于通过全局快捷键触发一组键盘、鼠标模拟操作。程序面向“按键触发 -> 顺序执行操作”的场景，需要支持多个配置项、全局启停、单配置启停、托盘运行、本地保存配置，以及 Windows 安装包打包。

核心目标：

1. 用户可以创建多个自动化配置，每个配置包含触发快捷键和动作序列。
2. 用户可以通过主界面、托盘菜单、全局快捷键控制配置运行状态。
3. 用户可以为每个配置设置独立启停快捷键。
4. 程序退出前必须停止所有配置并注销全局监听。
5. 配置需要保存到本地，重新打开后按保存状态恢复。

## 2. 产品范围

本期交付内容：

1. Tauri 桌面应用。
2. React + Ant Design 实现简洁清晰的单页配置界面。
3. 支持配置列表、创建、编辑、删除、启用、停用。
4. 支持全局总开关控制所有配置的运行态。
5. 支持配置全局启停快捷键。
6. 支持每个配置设置触发快捷键和启停快捷键。
7. 支持键盘组合键模拟。
8. 支持鼠标当前位置点击模拟，包括单击和双击。
9. 支持动作之间插入等待间隔。
10. 支持最小化隐藏到托盘。
11. 支持托盘右键菜单打开主窗口、切换总开关、切换配置、退出程序。
12. 支持点击关闭按钮时停止所有配置并退出程序。
13. 支持配置本地保存、启动恢复、导入和导出。
14. 支持 macOS 和 Windows。
15. 支持通过 GitHub Actions 打包 Windows 安装包。

## 3. 术语定义

| 术语 | 说明 |
| --- | --- |
| 配置 | 一个自动化规则，包含名称、启用状态、触发快捷键、启停快捷键、动作序列等信息。 |
| 触发快捷键 | 用户按下后执行动作序列的全局快捷键。 |
| 配置启停快捷键 | 用户按下后切换单个配置启用或停用状态的全局快捷键。 |
| 全局启停快捷键 | 用户按下后切换全局总开关开启或关闭状态的全局快捷键。 |
| 动作序列 | 触发后按顺序执行的一组键盘、鼠标或等待动作。 |
| 全局总开关 | 控制所有配置是否处于可运行状态的总开关。 |
| 运行态关闭 | 注销全局快捷键、停止监听和任务，不修改配置文件中保存的启用状态。 |

## 4. 总体行为

1. 触发快捷键只支持键盘组合键。
2. 鼠标左键和鼠标右键不能作为触发快捷键。
3. 鼠标左键、右键、中键可以作为模拟点击动作。
4. 鼠标点击动作点击当前鼠标所在位置。
5. 每个配置的启用状态需要持久化保存。
6. 全局总开关状态需要持久化保存。
7. 程序退出前必须运行态关闭所有配置，但不修改用户保存的配置启用状态。
8. 再次打开程序时，如果全局总开关处于开启状态，需要自动注册已启用配置。
9. 当全局总开关关闭时，配置触发快捷键暂停生效；配置启停快捷键和全局启停快捷键仍用于调整状态。
10. 单个配置快捷键注册失败时，仅该配置进入错误状态，不影响其他配置继续运行。

## 5. 功能需求

### 5.1 主界面

主界面使用单页布局，信息层级保持简洁。

顶部区域包含：

1. 应用名称：无敌小铃铛。
2. 全局总开关。
3. 全局启停快捷键设置入口。
4. 当前启用配置数量。
5. 新建配置按钮。
6. 导入配置按钮。
7. 导出配置按钮。

配置列表包含：

1. 配置名称。
2. 触发快捷键。
3. 配置启停快捷键。
4. 动作摘要。
5. 当前状态。
6. 启用/停用开关。
7. 编辑按钮。
8. 删除按钮。

界面状态要求：

1. 没有配置时展示空状态和新建入口。
2. 快捷键冲突、注册失败、权限不足时，在对应配置行或页面顶部展示简短错误提示。
3. 删除配置前需要二次确认。

### 5.2 配置管理

用户可以创建、编辑、删除配置。

配置字段：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| id | 是 | 程序生成的唯一标识。 |
| name | 是 | 配置名称。 |
| enabled | 是 | 单个配置是否启用。 |
| triggerHotkey | 是 | 触发动作序列的全局快捷键。 |
| toggleHotkey | 否 | 切换该配置启用或停用的全局快捷键。 |
| actions | 是 | 至少一个模拟动作。 |
| createdAt | 是 | 创建时间。 |
| updatedAt | 是 | 更新时间。 |

配置校验：

1. 配置名称不能为空。
2. 触发快捷键不能为空。
3. 触发快捷键必须至少包含一个普通键。
4. 触发快捷键不能是鼠标左键或鼠标右键。
5. 动作序列不能为空。
6. 同一平台内，已启用配置的触发快捷键不能重复。
7. 同一平台内，配置启停快捷键不能重复。
8. 同一配置内，触发快捷键不能与配置启停快捷键相同。
9. 全局启停快捷键不能与任何配置的触发快捷键、配置启停快捷键冲突。

### 5.3 全局总开关

全局总开关用于一键控制所有配置的运行态。

开启时：

1. 注册所有 `enabled = true` 的配置触发快捷键。
2. 注册所有配置的启停快捷键。
3. 注册全局启停快捷键。
4. 如果某个配置注册失败，仅该配置进入错误状态。

关闭时：

1. 注销所有配置的触发快捷键。
2. 停止所有等待执行或正在排队的动作。
3. 释放可能残留的按键或鼠标状态。
4. 配置的 `enabled` 字段保持不变。
5. 全局启停快捷键继续可用，用于重新开启全局总开关。

全局启停快捷键要求：

1. 用户可以配置一个可选的全局启停快捷键。
2. 按下全局启停快捷键后，切换全局总开关状态。
3. 全局启停快捷键需要持久化保存。

### 5.4 单个配置启停

每个配置都可以单独开启或关闭。

控制入口：

1. 主界面配置行开关。
2. 托盘菜单配置项。
3. 配置启停快捷键。

关闭单个配置时：

1. 注销该配置触发快捷键。
2. 如果该配置正在执行动作，本次执行应停止或尽快中断。
3. 保存最新启用状态。

开启单个配置时：

1. 保存最新启用状态。
2. 如果全局总开关开启，立即注册触发快捷键。
3. 如果全局总开关关闭，仅保存启用状态，不立即执行触发监听。

配置启停快捷键要求：

1. 按下后只切换该配置 `enabled` 状态。
2. 不执行动作序列。
3. 与触发快捷键、其他启停快捷键冲突时，需要提示用户修改。

### 5.5 触发快捷键

触发快捷键用于执行动作序列。

要求：

1. 支持键盘组合键。
2. macOS 示例：`Option + A`、`Command + A`、`Control + Shift + 1`。
3. Windows 示例：`Alt + A`、`Ctrl + A`、`Ctrl + Shift + 1`。
4. 快捷键录入使用“捕获快捷键”交互，用户按下组合键后自动填入。
5. 按住快捷键时不能无限重复触发，需要做防抖。
6. 默认防抖时间：300 ms。

### 5.6 动作序列

每个配置需要支持一个或多个动作，触发后按顺序执行。

动作类型：

| 动作类型 | 说明 | 示例 |
| --- | --- | --- |
| 键盘组合键 | 模拟按下并释放一组键盘组合键。 | `Command + A`、`Option + A`、`Ctrl + C` |
| 鼠标点击 | 模拟鼠标点击当前位置。 | 左键单击、左键双击、右键单击、中键单击 |
| 等待 | 等待指定毫秒数后继续下一步。 | 等待 100 ms |

动作字段：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| type | 是 | `keyCombo`、`mouseClick`、`delay`。 |
| keys | 条件必填 | `keyCombo` 动作需要填写。 |
| button | 条件必填 | `mouseClick` 动作需要填写，值为 `left`、`right` 或 `middle`。 |
| clickCount | 否 | 点击次数，默认 1，支持 1 或 2。 |
| durationMs | 条件必填 | `delay` 动作需要填写，单位为毫秒。 |
| delayAfterMs | 否 | 当前动作完成后的等待时间，默认 0，单位为毫秒。 |

执行示例：

1. 触发快捷键：`Command + A`
2. 动作序列：
   - 执行 `Option + A`
   - 等待 `100 ms`
   - 执行鼠标左键单击

### 5.7 执行控制

动作执行需要稳定、可控。

1. 同一配置正在执行时，再次触发默认忽略。
2. 全局动作执行使用串行队列，避免多个配置同时模拟输入造成错乱。
3. 动作执行期间，应避免模拟出来的按键再次触发其他配置。
4. 无法可靠区分真实输入和模拟输入时，动作执行期间临时暂停触发监听。
5. 全局总开关关闭、单个配置关闭、程序退出时，需要取消未执行的动作。
6. 程序捕获到执行错误时，需要释放所有可能按住的按键。

### 5.8 托盘行为

窗口与托盘行为：

1. 点击最小化时，主窗口隐藏到托盘，程序继续运行。
2. 隐藏到托盘后，已启用配置继续生效。
3. 点击托盘图标时，恢复显示主窗口。
4. 右击托盘图标时，展示托盘菜单。

托盘菜单包含：

1. 打开主窗口。
2. 全局总开关：开启/关闭。
3. 配置列表：每个配置一个菜单项，展示当前开启/关闭状态，点击后切换该配置状态。
4. 退出程序。

### 5.9 关闭与退出

关闭窗口行为：

1. 点击关闭按钮时，程序退出，不隐藏到托盘。
2. 托盘菜单点击退出时，程序退出。
3. 系统要求应用退出时，程序尽量执行统一清理流程。

退出前清理流程：

1. 停止所有配置。
2. 注销所有全局快捷键。
3. 停止所有监听。
4. 取消等待执行的动作。
5. 释放所有可能残留的按键或鼠标状态。
6. 保存最新配置。

### 5.10 配置持久化

配置需要本地保存。

1. 保存位置使用 Tauri 应用数据目录。
2. 保存格式使用 JSON。
3. 创建、编辑、删除、启停配置时立即保存。
4. 保存需要使用原子写入策略，避免程序崩溃导致配置文件损坏。
5. 启动时读取配置文件。
6. 配置文件不存在时使用空配置列表。
7. 配置文件损坏时，程序不崩溃，需要提示用户配置读取失败，并备份损坏文件后创建新的空配置。

建议配置结构：

```json
{
  "version": 1,
  "globalEnabled": true,
  "globalToggleHotkey": {
    "keys": ["Option", "Shift", "G"]
  },
  "configs": [
    {
      "id": "uuid",
      "name": "示例配置",
      "enabled": true,
      "triggerHotkey": {
        "keys": ["Option", "A"]
      },
      "toggleHotkey": {
        "keys": ["Option", "Shift", "A"]
      },
      "actions": [
        {
          "type": "keyCombo",
          "keys": ["Command", "A"],
          "delayAfterMs": 100
        },
        {
          "type": "mouseClick",
          "button": "left",
          "clickCount": 1
        }
      ],
      "createdAt": "2026-06-27T00:00:00.000Z",
      "updatedAt": "2026-06-27T00:00:00.000Z"
    }
  ]
}
```

### 5.11 配置导入导出

用户可以手动导入、导出配置。

要求：

1. 导出格式使用 JSON。
2. 导出内容包含 `version`、`globalEnabled`、`globalToggleHotkey` 和 `configs`。
3. 导入时需要校验配置结构和快捷键冲突。
4. 导入支持覆盖当前配置。
5. 导入支持追加到当前配置。
6. 追加导入时，如果配置 `id` 冲突，需要为导入项生成新的 `id`。
7. 导入失败时，不应破坏当前已保存配置。

## 8. 技术实现约束

## 9. 权限与错误处理

需要覆盖以下错误场景：

1. 缺少系统权限。
2. 快捷键被系统或其他应用占用。
3. 快捷键配置冲突。
4. 配置文件读取失败。
5. 配置文件写入失败。
6. 配置导入失败。
7. 配置导出失败。
8. 动作执行失败。
9. 托盘初始化失败。

错误展示原则：

1. 配置级错误展示在配置行。
2. 全局错误展示在页面顶部提示条。
3. 权限错误需要提供进入系统设置的说明或入口。
4. 核心功能不可用时可以使用弹窗打断用户。

## 10. 验收标准

### 10.1 配置与触发

1. 用户可以新建一个触发快捷键为 `Option + A` 的配置。
2. 用户可以为该配置添加动作：`Command + A`、等待 `100 ms`、鼠标左键单击。
3. 保存后按下 `Option + A`，程序按顺序执行上述动作。
4. 鼠标左键、右键不能被配置为触发快捷键。
5. 用户可以把鼠标点击动作配置为双击。
6. 关闭该配置后，按下触发快捷键不再执行动作。
7. 重新开启该配置后，按下触发快捷键恢复执行动作。

### 10.2 全局控制

1. 全局总开关关闭后，所有配置触发快捷键均不生效。
2. 全局总开关开启后，已启用配置恢复生效。
3. 全局总开关关闭不会把单个配置的启用状态改成关闭。
4. 用户可以配置全局启停快捷键。
5. 按下全局启停快捷键后，全局总开关状态切换。

### 10.3 配置启停快捷键

1. 用户可以为配置设置启停快捷键。
2. 按下配置启停快捷键后，该配置在开启和关闭之间切换。
3. 配置启停快捷键不能与其他配置快捷键冲突。

### 10.4 托盘与退出

1. 点击最小化后，窗口隐藏到托盘，配置继续生效。
2. 托盘右键菜单可以打开主窗口。
3. 托盘右键菜单可以切换全局总开关。
4. 托盘右键菜单可以切换每个配置。
5. 点击窗口关闭按钮后，程序停止所有配置并退出。
6. 托盘菜单点击退出后，程序停止所有配置并退出。

### 10.5 持久化

1. 创建配置后关闭程序，再次打开配置仍存在。
2. 配置启用状态、全局总开关状态再次打开后保持一致。
3. 配置文件损坏时，程序不崩溃，并提示配置读取失败。

### 10.6 导入导出

1. 用户可以导出当前配置为 JSON 文件。
2. 用户可以把导出的 JSON 文件重新导入。
3. 覆盖导入后，当前配置被导入文件替换。
4. 追加导入后，导入配置追加到当前配置列表。
5. 导入失败不会破坏当前配置。

### 10.7 Windows 打包

1. 推送 `v*` tag 后触发 Windows 打包 workflow。
2. 手动触发 workflow 可以生成 Windows 安装包。
3. Workflow 成功后可以下载 `.exe` artifact。
